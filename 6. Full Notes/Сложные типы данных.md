- **[[Списки Python]]**
```python
# Список (упорядоченный, изменяемый)
fruits = ["яблоко", "банан", "вишня"]
```
- **[[Кортежи Python]]**
```python
# Кортеж (упорядоченный, неизменяемый)
coordinates = (10.5, 20.7, 30.9)
```
- **[[Множества Python]]**
```python
# Множество (неупорядоченный, только уникальные элементы)
unique_numbers = {1, 2, 3, 4, 5}
```
- **[[Словари Python]]**
```python
# Словарь (пары ключ-значение)
person = {"name": "Алекс", "age": 30, "city": "Москва"}
```

| Тип данных          | Синтаксис        | Основные свойства                                                       | Когда использовать                                                                           |
| ------------------- | ---------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Список (list)**   | [1, 2, 3]        | ✅ Изменяемый  <br>✅ Упорядоченный  <br>✅ Доступ по индексу              | Когда важен порядок и нужно изменять коллекц                                                 |
| **Кортеж (tuple)**  | (1, 2, 3)        | ❌    Неизменяемый  <br>✅ Упорядоченный  <br>✅ Доступ по индексу         | Для защиты данных от изменений (координаты, констан                                          |
| **Множество (set)** | {1, 2, 3}        | ✅ Изменяемый  <br>❌ Неупорядоченный  <br>❌ Нет индексов               Когда нужны только уникальные элементы<br>Для создания пустого множества использовать set() ать  |
| **Словарь (dict)**  | {"key": "value"} | ✅ Изменяемый  <br>✅ Упорядоченный (с Python 3.7)  <br>✅ Доступ по ключу | Для связи значений с уникальными кл                                                          |
####  Преобразование
```python
# Создаем список
my_list = [1, 2, 3, 3, 4, 5]

# Преобразуем список в кортеж
my_tuple = tuple(my_list)  # (1, 2, 3, 3, 4, 5)

# Преобразуем список во множество (дубликаты будут удалены)
my_set = set(my_list)  # {1, 2, 3, 4, 5}

# Создаем словарь из списка пар
pairs = [("a", 1), ("b", 2), ("c", 3)]
my_dict = dict(pairs)  # {"a": 1, "b": 2, "c": 3}
```
