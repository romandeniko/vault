Объект базы данных, являющийся результатом выполнения запроса к БД, определенного с помощью оператора `SELECT`, в момент обращения к представлению.

Представления позволяют изменить то, каким образом данные отображаются при запросе.

```sql
CREATE VIEW ViewUsers AS
    SELECT id,
           name,
           CONCAT(SUBSTR(email, 1, 2), '****', RIGHT(email, 4)) AS email
FROM Users;
```

### Синтаксис
```sql
CREATE [OR REPLACE] VIEW имя_представления [(имена_полей_представления)]
AS select_выражение
```

`REPLACE` -- если представление с таким именем уже существует, старое представление будет удалено, а новое создано.
