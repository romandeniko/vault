### Округление времени
```sql
SELECT
    DATE_TRUNC('month', '2024-03-15'::date) AS by_month,
    DATE_TRUNC('week',  '2024-03-15'::date) AS by_week,
    DATE_TRUNC('year',  '2024-03-15'::date) AS by_year;
```

### Паттерн для анализа
```sql
-- Сначала группируем
WITH daily AS (
    SELECT
        DATE_TRUNC('day', order_date) AS day,
        SUM(total_amount) AS revenue
    FROM orders
    WHERE status = 'delivered'
    GROUP BY day
)
-- Потом накладываем окно
SELECT
    day,
    revenue,
    SUM(revenue) OVER (ORDER BY day) AS cumulative_revenue
FROM daily;
```
