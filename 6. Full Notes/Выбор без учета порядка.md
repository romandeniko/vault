Сочетание из *n* по *k*: наборы из различных k элементов, выбранные из множества с *n* элементами, для которых порядок выбора не имеет значения.

Количество сочетаний записывают как $C\frac{k}{n}$​ (от слова ”combinations”). Внизу пишут мощность исходного множества, а наверху — количество выбираемых элементов.

В общем виде формула для подсчета количества k-сочетаний из n будет выглядеть:

$$c\frac{k}{n} = \frac{n(n-1)(n-2)...(n-k+1)}{k!}$$
