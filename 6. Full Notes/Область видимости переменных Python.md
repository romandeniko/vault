Правило, по которому Python решает, какая пеерменная имеется в виду в каждом месте кода. Часть программы, в которой доступна переменная.

Два уровня видимости:
* **глобальная**: видно в любой функции;
```python
# Создаём глобальную переменную
message = "Привет, мир!"

def show_message():
    # Используем глобальную переменную внутри функции
    print(message)

show_message()
```
* **локальная**: переменные объявляются внутри функции и живут только пока функция выполняется
```python
def calculate_sum():
    a = 10
    b = 20
    result = a + b
    print(f"Сумма внутри функции: {result}")

calculate_sum()
```

Если внутри функции создается локальная переменная, которая имеет то же имя, что и глобальная переменная, приоритет отдается локальной переменной.

##### Изменение глобальной переменной из функции
```python
def calculate_sum():
    a = 10
    b = 20
    result = a + b
    print(f"Сумма внутри функции: {result}")

calculate_sum()
```
