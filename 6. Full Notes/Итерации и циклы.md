### Цикл for
```python
fruits = ["яблоко", "банан", "вишня"]

for fruit in fruits:
    print(f"Фрукт: {fruit}")
```

```python
for i in range(3):
    print(i, end=" ")
print()
```

```python
# range(start, stop): от start до stop-1
for i in range(2, 5):
    print(i, end=" ")
print()
```

```python
# range(start, stop, step): от start до stop-1 с шагом step
for i in range(1, 10, 2):  # Нечетные числа от 1 до 9
    print(i, end=" ")
```

```python
message = "Python"

for char in message:
    print(char)
```

```python
fruits = ["яблоко", "банан", "вишня"]

for index, fruit in enumerate(fruits):
    print(f"Индекс {index}: {fruit}")
```

### Цикл while
```python
counter = 0

while True:  # Это условие всегда истинно
    print(f"Итерация {counter}")
    counter += 1

    if counter >= 5:  # Условие для выхода из цикла
        print("Выходим из цикла!")
        break  # Прерывает выполнение цикла
```

### Управление циклами

* `break` -- немедленный выход из цикла, независимо от условия:
```python
for i in range(10):
    print(i, end=" ")
    if i == 5:
        print("\nДостигнуто число 5, выходим из цикла!")
        break
```

* `continue` -- пропускает текущую итерацию и переходит к следующей:
```python
for i in range(10):
    print(i, end=" ")
    if i == 5:
        print("\nДостигнуто число 5, выходим из цикла!")
        break
```

```python
for i in range(5):
    print(i, end=" ")
else:
    print("\nЦикл завершился без break")
```

### Вложенные циклы
```python
# Пример вложенных циклов - таблица умножения
for i in range(1, 4):  # Строки
    for j in range(1, 4):  # Столбцы
        print(f"{i} × {j} = {i*j}", end="\t")
    print()  # Переход на новую строку после каждой строки таблицы
```

### Генераторы списков
```python
# Создание списка квадратов чисел от 0 до 9
# Обычный способ
squares = []
for i in range(10):
    squares.append(i**2)
print(f"Обычный способ: {squares}")
```

```python
# С использованием списковых включений
squares_comprehension = [i**2 for i in range(10)]
print(f"Через списковое включение: {squares_comprehension}")
```

```python
# Фильтрация с помощью условия: только четные числа
even_squares = [i**2 for i in range(10) if i % 2 == 0]
print(f"Квадраты четных чисел: {even_squares}")
```
