### Использование CASE WHEN
```sql
SELECT
    to_char(order_date, 'YYYY-MM') AS month,
    SUM(CASE WHEN status = 'delivered' THEN 1 ELSE 0 END) AS delivered,
    SUM(CASE WHEN status = 'canceled' THEN 1 ELSE 0 END) AS canceled,
    SUM(CASE WHEN status = 'refunded' THEN 1 ELSE 0 END) AS refunded
FROM orders
WHERE order_date >= '2024-01-01' AND order_date < '2024-07-01'
GROUP BY month
ORDER BY month;
```

### Использование FILTER
```sql
SELECT
    to_char(order_date, 'YYYY-MM') AS month,
    COUNT(*) FILTER (WHERE status = 'delivered') AS delivered,
    COUNT(*) FILTER (WHERE status = 'canceled') AS canceled,
    COUNT(*) FILTER (WHERE status = 'refunded') AS refunded
FROM orders
WHERE order_date >= '2024-01-01' AND order_date < '2024-07-01'
GROUP BY month
ORDER BY month;
```

####  Проценты с обработкой NULL

```sql
SELECT
    to_char(order_date, 'YYYY-MM') AS month,
    COALESCE(SUM(total_amount) FILTER (WHERE status = 'delivered'), 0) AS revenue,
    COALESCE(SUM(total_amount) FILTER (WHERE status = 'refunded'), 0) AS refunded_amount,

    -- Теперь математика в безопасности!
    COALESCE(SUM(total_amount) FILTER (WHERE status = 'delivered'), 0) -
    COALESCE(SUM(total_amount) FILTER (WHERE status = 'refunded'), 0) AS net_revenue
FROM orders
WHERE order_date >= '2023-02-01' AND order_date < '2023-05-01'
GROUP BY month
ORDER BY month;
```
