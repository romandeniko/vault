Разрабатывает и формализует требования для ПО, соединяя бизнес-цели с техническими возможностями.

**Обязанности**:

- Анализировать потребности бизнеса и переводить их в формальные требования
- Проектировать архитектуру систем и описывать её компоненты
- Создавать диаграммы и документацию
- Взаимодействовать с командой разработки и заказчиком
- Помогать в тестировании и приёмке решений

**Типы ИТ-систем, с которыми работает системный аналитик**

| `Категория`                            | `Примеры`                   |
| -------------------------------------- | --------------------------- |
| ERP – управление ресурсами предприятия | SAP, Oracle ERP             |
| CRM – управление клиентами             | Salesforce, Битрикс24       |
| SCM – логистика и цепи поставок        | SAP SCM, Oracle SCM         |
| HRM – управление персоналом            | Workday, SAP SuccessFactors |
| BI – аналитика данных                  | Power BI, Tableau           |
**Навыки**
- Глубокое понимание бизнес-процессов
- Знание методов анализа требований
- Опыт работы с архитектурными моделями
- Владение инструментами моделирования (UML, BPMN)
- Навыки работы с SQL и REST API
