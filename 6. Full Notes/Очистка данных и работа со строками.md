**Правило GIGO**
Если на вход подать некорректные данные, вывод будет некорректным. До 50-80% работы аналитика уходит на подготовку данных.

**1. Приведение к единому формату: LOWER () и TRIM()**
```sql
SELECT
    email AS original_email,
    LOWER(TRIM(email)) AS clean_email
FROM users
LIMIT 5;
```

**2. Удаление лишних символов: REPLACE ()**
```sql
SELECT
    phone AS original_phone,
    REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(phone, '+', ''), ' ', ''), '(', ''), ')', ''), '-', '') AS clean_phone
FROM users
LIMIT 5;
```

**3. Извлечение данных из строки**
```sql
SELECT
    SUBSTRING_INDEX(LOWER(TRIM(email)), '@', -1) AS domain,
    COUNT(*) AS users_count
FROM users
GROUP BY domain
ORDER BY users_count DESC;
```

**4. Преобразование NULL**
```sql
SELECT COUNT(*) AS real_promo_orders
FROM orders
WHERE NULLIF(TRIM(promo_code), '') IS NOT NULL;
```
