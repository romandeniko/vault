Имя привязанное к объекту в памяти.
Переменные в Python:
* не нужно объявлять заранее;
* не нужо указывать тип;
* можно перепривязать имя к другому значению в любой момент

```python
# Создание переменных различных типов
name = "Иван"          # Строковая переменная
age = 25               # Целочисленная переменная
height = 1.85          # Переменная с плавающей точкой
is_student = True      # Логическая переменная
courses = ["Python", "SQL", "JavaScript"]  # Переменная-список
```

##### Множественное присваивание
```python
coordinates = (10, 20, 30)
x, y, z = coordinates
print(f"x={x}, y={y}, z={z}")
```

```python
a = 5
b = 10
a, b = b, a
print(f"a = {a}, b = {b}")
```

##### Динамическая типизация
```python
x = 10 # x имеет тип int (целое число)
print(f"x = {x}, тип: {type(x)}")
```

```python
x = "десять" # теперь x имеет тип str (строка)
print(f"x = {x}, тип: {type(x)}")
```

```python
x = [1, 2, 3] # теперь x имеет тип list (список)
print(f"x = {x}, тип: {type(x)}")
```

##### Именование
* Имя переменной может содержать буквы, цифры, символ подчеркивания `(a-z, A-Z, 0-9, _)`.
* Имя должно начинаться с буквы или подчеркивания.
* Нельзя использовать зарезервированные слова.
* Необходимо использовать описательные имена.
* Необходимо использовать snake_case.
* Использовать префикс для логических переменных: `is_adult, has_permission`.
* использовать верхний регистр для констант.
